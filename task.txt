Тестовое задание для соискателей на должность
 «Старший программист» в ООО «Нетнуклеус Софт»

Описание задания:  
разработать клиентское приложение (web-installer), которое скачивает и запускает другое приложение.
рассчитать статистику работы приложения
опционально: реализовать тестовый стенд (сервер) 
Пример скачиваемого приложения: 7-zip (https://www.7-zip.org/)
Требования:
Среда разработки: Visual Studio 2022 
Клиентское приложение должно быть создано с использованием языка С++, которое должно удовлетворять следующим требованиям: 
Удобный графический интерфейс с индикатором прогресса скачивания файла.
Графический интерфейс не должен подвисать. 
2 режима работы в зависимости от аргументов командной строки. В первом режиме работа с сетью должно быть реализована через wininet функции. Во втором режиме через curl lib.
ОБРАТИТЕ ВНИМАНИЕ: curl lib требуется собрать из исходников самостоятельно.
Запуск по умолчанию должен быть с правами родительского процесса. При запуске, если процесс запущен без прав администратор, необходимо запросить права администратора. При отказе пользователя предоставить права администратора приложение должно продолжить работу.
Отправка результатов работы приложения на сервер:
- начало работы приложения
- режим работы (wininet\curl)
- результат запроса на элевацию (разрешена\отклонена)
- результат запуска скаченного приложения
Запрос файла у сервера. При отсутствии файла или при любом ошибочном ответе от сервера файл необходимо распаковать из секции ресурсов приложения.
Тип взаимодействия с сервером: http(s) запросы. Формат сообщений на усмотрение соискателя.
При сетевой ошибке необходимо повторить запрос спустя небольшой промежуток времени (один раз).
При любой сетевой ошибке кроме ошибки в процессе запроса на скачивание файла – необходимо выдать текстовое сообщение и завершить работу
Скаченный/распакованный файл должен быть успешно запущен по окончанию работы приложения в любом сценарии, кроме случаев с ошибкой при взаимодействии с сервером.
Приложение должно представлять собой один исполняемый файл, не требующий наличия дополнительных библиотек в системе пользователя.
Приложение должно полностью работать на чистых операционных системах семейства Windows 10, 11(x86, x64) без установки дополнительных пакетов. Проверить работоспособность приложения можно на виртуальных машинах VMWare и др. 

Пример тестового стенда будет предоставлен дополнительно. Опционально соискатель может реализовать свой тестовый стенд, который будет:
Принимать запросы от клиента.
Отправлять файл или ошибку в ответ на запрос на скачивание файла.
Писать результаты работы клиента в БД (например  sqlite)
Необходимо провести тестирование работы приложения в различных сценариях поведения и произвести расчёт количества успешных запросов на права администратора, отклонённых запросов на права администратора и успешных запусков итогового файла (в процентах от количества запусков).

В качестве результата тестового задания необходимо предоставить:
Приложение и его исходники
Конфигурацию тестового стенда (опционально)
Результаты расчёта статистики по запускам
